# Imágenes del sistema

- `ICONO.png`: icono de la pestaña del navegador, con el título ReviewFlow.
- `LOGO.png`: logo que reemplaza A-Review en la cabecera de la barra lateral.

Conserva estos nombres al reemplazar las imágenes (incluidas las mayúsculas).

- `fondo-login.svg`: patrón vectorial repetido, usado solo en el login.
- `FONDO.png`: referencia original; el login no descarga este archivo.

- `fondo-sistema.svg`: patrón claro de las pantallas internas, inspirado en `FONDO2.png`. La imagen original no se descarga en estas pantallas.
